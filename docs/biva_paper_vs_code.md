# BIVA 논문–코드 대조 (2026-11-06)

논문: 김의철(2023), 「동적 요인 모델을 기반으로 한 시계열 딥러닝 모델 개발 및 Nowcasting GDP에 대한 실증연구」, 서울벤처대학원대학교 박사학위논문. 쪽수 = 인쇄 쪽(PDF 쪽 = 인쇄 + 16).
코드: `models/biva_src/`(연구실 원본 사본), 학습 루프 `models/biva.py`, 원본 노트북·로더 `legacy/biva_orig/`.

## 결론
- **신경망 구조는 논문 부록 모델 요약표(140–142쪽)와 층 구성이 같다.** 구조 그림은 [그림 15](70쪽): Stage 1 결측값 삽입(BRITS) → Stage 2 추세·주기 분해 → Stage 3 주기정보 차원감소(LSTM-VAE) → Stage 4 예측(가중 합).
- **과제·데이터 처리·하이퍼파라미터·평가는 논문과 다르다.** 연구실 노트북은 GDP 가 아니라 서울 주택매매가격지수(F11) 수준값을 맞히도록 바뀐 판이다 → 코드 실행 결과를 논문 결과의 재현으로 쓰면 안 된다.
- 논문이 BRITS 로 채우려 한 빈 칸 세 종류: ① 분기 변수의 분기 사이(그림 27, 추론) ② 창 끝 공표시차 칸 = ragged edge(국문요약·그림 27·그림 35, 명시) ③ 늦게 시작한 변수(112–113쪽, 명시). **원본 코드는 ②를 하지 않는다**(`set_lag_missing` 주석 처리, 되살려도 오류).
- "공통요인(latent factor)"의 뜻은 **주기 성분의 VAE 잠재변수 z** 에만 있다(DFM 의 요인 추출에 대응). 추세 경로는 차원감소 없이 바로 예측(본문 "단순 MLP", 코드 Conv1d 3단 + Linear, 활성함수 없음 = 선형).

## 항목별

| 항목 | 논문 | 코드 | 판정 |
|---|---|---|---|
| 예측 대상 | 분기 실질 GDP 성장률(당분기 nowcast, DMS 3-step) | 노트북: F11 수준값 1-step | 다른 과제 |
| 라벨 | 분기 라벨을 각 월에 대응 | 입력 마지막 행 = 정답(누출). 플랫폼은 k 기간 뒤 값으로 수정 | 불일치·누출 |
| 혼합주기 | 분기 변수는 분기말 행에만, 나머지 공란 | 같음(df_Q 결합 → NaN). 플랫폼은 ffill 로 채움 | 원본 일치 / 플랫폼 다름 |
| 공표시차 | 창 끝 lag 칸을 비우고 BRITS 로 채움 | 꺼짐(누출). 플랫폼은 공개일 기준 정렬 | 불일치 |
| 늦게 시작한 변수 | BRITS 로 채움 | 같음(use_brits) | 일치 |
| 스케일 | Min-Max | 학습 fit 후 전체 기간으로 재-fit(누출), 대상은 스케일 안 함 | 누출 |
| BRITS 추정 | x̂ = W·h + b (선형) | x̂·ẑ 모두 sigmoid | 불일치 |
| BRITS 결합 | 식에 결합 비율 없음 | `|0.5·ẑ + 0.5·x̂|` 고정. 학습 비율 β(weight_combine)·γ_x·dropout 은 계산만 하고 안 씀 | 코드 고유 |
| δ(시간 간격) | 마지막 관측 뒤 시간 | 시점 t−1 대신 이웃 변수 열 d−1 참조 | 코드 버그(원본 유지) |
| Stage 1 손실 | 양방향 손실 + 일관성, 가중치 없음 | (이력 L1 + 특징 L1) × imputed_weight(0.05) + 0.1 × 일관성 | 가중 불일치 |
| 분해 | 이동평균 추세, 주기 = 원래 − 추세. 커널 미기재 | 같음, 커널 6 | 일치 |
| LSTM-VAE | 잠재요인 분포, 손실 KL + 재구축 | 인코더 LSTM 4단, μ·logσ² 에 ReLU(σ ≥ 1), 손실 0.5·MSE + 0.5·KLD(합산 때문에 실제 0.5·잠재·MSE + 0.5·ΣKLD) | 구조 일치, 0.5 가중·ReLU 는 본문에 없음 |
| 주기 예측 head | 잠재요인 → MLP | [인코더 출력 ‖ z] → Conv1d → Linear | 요약표와 일치, 본문엔 이어붙임 언급 없음 |
| 합성 | 학습 비율 가중 합 | α·주기 + (1−α)·추세, α 학습(제약 없음) | 일치 |
| 예측 때 z | 언급 없음 | eval 에서도 무작위 표본 → 예측이 확률적 | 논문에 없음 |

| 데이터 | 월 96 + 분기 6 = 102개, 2000.01–2023.02, X-13 계절조정 | 서울 거시 34개, 2009–2025 | 다름 |

## 확인 못 한 것
- 부록 요약표의 채널 96 과 본문 102개 변수의 차이.
- 분기 라벨을 각 월 창에 어떻게 대응시켰는지(창이 분기 첫 달에서 끝날 때).
- 논문에서 쓴 이동평균 커널 크기.

## 플랫폼 그림에 반영(2026-11-06)
- 블록 이름을 논문 Stage 1–4 로. BRITS 결합을 코드대로 고정 0.5:0.5 로 표기(이전 그림의 "β 학습"은 틀렸음 — 정정). 추세 경로는 "차원감소 없이 선형 예측", '공통요인' 은 VAE z 에만.
- 입력이 계절조정돼 있으면 'Seasonal' 은 계절성보다 이동평균을 뺀 단기 변동이다 → 그림에서는 "주기" 로 표기.
