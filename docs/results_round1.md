## 결론

2. **Buy&Hold(CAGR 14.2%, 샤프 0.57)를 이긴 전략이 없다.** 초과수익 부트스트랩 p값 0.90~1.00.
3. **월간 주기에서만 다른 신호가 보인다**: LightGBM(A+B+C+D) 방향 정확도 55.8%, DM 검정에서 0 예측과 차이 없음(p=0.68), 샤프 0.48. 129개월 표본이라 55.8%의 신뢰구간은 ±8.6% — **우연과 구분되지 않는다.** 거시변수가 월간에서 유효하다는 가설의 "후보"일 뿐 근거는 아니다.
4. 규칙 기반 MA 교차(20/60)가 모든 ML을 이겼다(샤프 0.52). 그래도 Buy&Hold보다 못하다.
5. BIVA(원본 구조, 축소 기본값)는 일간에서 방향 48.8%, 샤프 0.12로 최하위권. 기존 월간 부동산 실험의 결론(naive보다 못함)과 일관된다.

## 정정 (2026-11-03) — 월간 후보 철회

- 12번(월간 LightGBM A+B+C+D, dir_acc 55.8%)은 **모델이 입력을 전혀 쓰지 않은 퇴화 실행**이었다. 학습 표본 60개월에 `min_child_samples=40`(일간용 기본값)이라 트리가 한 번도 분할하지 못했고, 예측은 폴드별 학습구간 평균(거의 항상 양수)이었다. 55.8%는 "항상 롱"의 적중률(그 기간 양의 달 비율)이다. 중요도 전부 0 으로 확인.
- `min_child_samples=8` 로 실제 학습시키면 dir_acc 50.4%, DM 3.43(p=0.0006) — **0예측보다 유의하게 나쁨.** 샤프 0.322(B&H 0.565 미만).
- 따라서 1차 실험의 결론은 **"일간·주간·월간 모두 예측 신호 없음"** 으로 바뀐다. 월간은 표본(129개월)이 작아 LightGBM 자체가 부적합할 수 있으므로, 월간은 Ridge 같은 저용량 모델로 다시 보는 것이 맞다.
- 엔진에 퇴화 검사 추가: 중요도 합이 0 이면 결과에 `degenerate_model=true` 와 경고. ablation 표에서 모든 변형이 동일한 수치를 낸 것이 발견 계기였다.
- 일간·주간 ML 실행(04~09, 11)은 중요도가 0 이 아니어서 이 문제는 없다.
