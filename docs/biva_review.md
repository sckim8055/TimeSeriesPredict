## 1. 결론 먼저

1. **원본 코드에는 타겟 누출이 있다**(정답이 입력 마지막 행에 포함). 코드와 날짜 진단으로 확정.
2. **그러나 BIVA는 누출된 정답을 베끼는 것조차 학습하지 못했다.** 정답을 입력에 넣어 준 조건에서도 RMSE 1.93(베끼면 0).
3. **누출을 고친 뒤 BIVA의 실제 예측 성과는 "다음 달 = 이번 달"(naive)보다 4~5배 나쁘다.** 1개월 예측 RMSE 3.08 vs naive 0.66 vs ARIMA 0.26.
4. 타겟을 변화량으로 바꾸면 naive 수준(0.71)까지는 오지만 그 이상은 못 간다.
5. 교재 17장의 "예측선이 실제선과 거의 포개진 그래프"는 **지수 범위(82~100)에 비해 오차(약 3)가 작아 보이기 때문**이지, 예측이 좋아서가 아니다. naive 선을 함께 그리면 BIVA가 더 멀리 떨어져 있다.

→ **플랫폼에는 BIVA를 "비교 대상 모델"로 넣되, 교재·연구 결과에서 BIVA의 성과를 근거로 쓴 부분은 재검토가 필요하다.**

## 4. 무엇을 어떻게 고쳤나 (`legacy/biva_fixed/run_fixed.py`)

- **[F1] 타겟 정렬**: 정답 = 입력 윈도우 *다음* `pred_len`개 시점. `--leak` 옵션으로 원본 방식 재현 가능.
- **[F2] 스케일러**: 학습 구간(60%)에만 fit, 나머지는 transform.
- **[F3] 손실**: 타겟도 스케일, `w_pred·MSE + w_vae·VAE + w_imp·Imputation` (기본 1.0 / 0.1 / 0.05).
- **[F4 실험] `--diff`**: 변화량 타겟. 비정상(추세) 시계열에서 수준 타겟의 한계 확인용.
- 신경망 코드(`model/BIVA*.py`)는 원본 그대로(장치 패치 1줄, import 패치 1줄). 학습 루프는 원본과 동일 조건(Adam, lr 0.01→10에폭 후 0.001, 배치 3, 500에폭, 검증 최저 체크포인트).
- `legacy/biva_orig_run`은 원본 로직을 그대로 두고 경로·장치·기간(2009-01)만 패치한 "원본 재실행용".

## 5. 해석

- 수준(level) 타겟의 BIVA 예측은 실제 선을 **뒤따라가는** 형태다(초반 과소, 후반 과대). 이는 추세가 있는 비정상 시계열을 수준으로 학습한 모델의 전형적 현상이고, 그래서 차분 모델(ARIMA d=1)과 naive가 압도적으로 유리하다.
- 변화량 타겟으로 바꾸면 모델은 "변화 ≈ 0"을 학습해 naive에 수렴한다. 34개 거시변수에서 월간 변화 방향을 읽어내지는 못했다.
- 이 결과는 BIVA 구조 자체의 결함을 뜻하지 않는다. **195개월 표본은 이 크기의 신경망을 학습시키기에 너무 작다.** 일간 데이터(4,800개)나 여러 지역 통합 학습에서는 결과가 다를 수 있다 — 플랫폼에서 검증할 문제다.
- 교재 17·18장에서 BIVA 성과를 서술한 부분, 연구실 실험 CSV(2025-08~2026-02, 50여 건)는 모두 문제 1~3 상태의 수치다.

## 6. 플랫폼에 반영할 것

1. 모든 비교 화면에 naive 기준선을 강제 표시(이미 기획에 있음 — 이 사례가 이유).
2. 수준 타겟을 기본에서 제외하고 수익률/변화량 타겟만 허용(기획 4장과 일치).
3. 누출 검사(타겟 섞기)와 함께 **"입력에 정답 포함" 검사**를 추가: 정답 날짜가 입력 날짜 범위 안에 있으면 즉시 실패.
4. BIVA 플러그인은 `legacy/biva_fixed/model/` 4파일을 `models/biva.py` 1파일로 합쳐서 이식. 기본 하이퍼파라미터는 표본 수에 맞춰 축소(hidden 32~64, 레이어 2).

## 7. 재현 방법

```
cd legacy/biva_orig_run/model && python run_original.py 1 500     # 원본 재실행
cd legacy/biva_fixed && python run_fixed.py --leak --pred_len 1   # 누출 재현
cd legacy/biva_fixed && python run_fixed.py --pred_len 1          # 수정본 (3, 6 도 가능)
cd legacy/biva_fixed && python run_fixed.py --diff --pred_len 1   # 변화량 타겟
cd legacy && python baselines.py                                   # naive, ARIMA
```
필요 패키지: torch, pandas<3, statsmodels, scikit-learn, openpyxl. 1회 실행 약 15~20분(CPU).
