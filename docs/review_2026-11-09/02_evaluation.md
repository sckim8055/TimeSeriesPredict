# 점검 보고 — 평가·통계·다중검정 (backtest / metrics / DM / bootstrap / DSR / 사전 등록 / 판정)

점검 범위: `engine/backtest.py`, `engine/experiment.py`(지표·DM·DSR·카운터), `cli.py`, `api/main.py`(Holm), `web/src/Results.tsx`(판정 배지), `engine/sealed.py`, `results/trading|forecast/*.json·parquet`, `docs/DECISIONS.md`, `docs/GUIDE.md` 엔진 알고리즘 절. 재계산은 저장된 parquet·json 과 합성 자료로 직접 했다(재실험 없음). 저장소 파일은 고치지 않았다.

## 1. 총평

체결 회계(t 결정 → t+1 시가 진입 → t+2 시가 청산, 전환 때만 비용)와 성적표, DM 의 Newey–West 분산, DSR 수식은 저장 결과 파일로 끝자리까지 재계산되고 statsmodels HAC 와도 일치한다 — "돌아가고 값도 맞는다". 문제는 **통계 장치의 설계와 운용**에 있다. (1) DSR 의 N(전역 카운터 98)과 V(살아남은 26개 결과의 샤프 분산)는 표본이 다를 뿐 아니라, 같은 설정은 파일을 덮어써 사라지고, 옛 13개 결과는 **봉인 구간(2025~2026-11)을 포함해 평가된 것인데 지금도 리더보드와 V 에 들어 있다**. (2) 저장된 DSR p 는 결과마다 다른 N(2~98)으로 계산돼 리더보드 'Defl p' 열은 행끼리 비교할 수 없다(같은 B&H 가 N=2 면 p 0.035, N=93 이면 0.84). (3) 사전 등록 기준은 문서·코드에 3판본이 있고, '봉인 구간 방향 일치'는 코드 어디에도 구현·정의되지 않았으며 F11 처럼 지속성이 강한 지수에서는 naive 도 94% 맞히는 무의미한 기준이다. (4) 세 기준을 동시에 만족하려면 N=98 에서 일간 연 샤프 약 1.0 이 필요해(B&H 0.31) 이 자산·기간에서 "신호 있음"은 사실상 도달 불가능한 기준이다 — 틀린 것은 아니나 "통과 전략 없음"이 기준 설계의 귀결임을 논문에 밝혀야 한다. (5) 매매 모드에는 전략 간 다중비교(White RC/SPA/Romano–Wolf)가 없고 DSR 만 있다.

### 건의

- **S1. 기준은 이 자산·기간에서 도달 불가능에 가깝다 — 명시.** 현재 V·N=98·n=3116·왜도 −0.3·첨도 8 에서 DSR p<0.05 에 필요한 연 샤프 ≈ **1.03**(주간 1.19, 월간 1.37; N=1 이어도 0.47). B&H 개발 구간 0.31. "통과 전략 없음"은 기준 설계의 귀결임을 적고 보조로 부트스트랩+SPA 를 보고.
- **S2. DM vs 0예측은 매매 신호 검정으로 약함.** d=ŷ²−2ŷy 는 크기 오차를 벌함; 신호는 1[ŷ>0] 만 씀 → Pesaran–Timmermann 또는 경제적 손실 DM 병행. 예측 모드에선 0예측이 거의 자동 통과(F11 네 모델 p<0.03) → naive 만 실질 기준(GUIDE 2064 에 이미 적힘).
- **S3. naive 는 적절하나 '추세 RW' 기준선 없음.** F11 월간 변화율 평균 0.34%·sd 0.55%·ρ₁ 0.82 → 재계산 RMSE: zero 0.00643 / 확장평균(추세 RW) 0.00587 / 36개월 평균 0.00561 / **AR(1) 0.00332 / naive 0.00328** / Ridge 0.00413. naive≈AR(1)(DM p 0.72) 이라 선택 타당. 결과 파일에 `rmse_drift` 한 줄 추가 권장(비용 작음).
- **S4. B&H 초과수익 귀무가설 재고.** 롱/현금은 노출<1 → 양의 추세 자산에서 구조적으로 음의 초과. 같은 노출의 무작위 타이밍 귀무 또는 노출 보정 α. DECISIONS 11-03 '2022 약세장 폴드 별도 보고' 미구현.

## 3. 확인해서 문제없던 것

- 체결·비용·자산곡선: `hold=open[t+2]/open[t+1]−1`, `net=pos·hold−|Δpos|·0.00065`, `equity=Π(1+net)` 이 02_ma_cross_v1107 parquet 4317행 전부 일치; 성적표(샤프 0.26168, CAGR 0.03222) json 과 끝자리 일치. 비용은 전환 때만, 현금 수익 0, 마지막 청산 비용 없음(문서화됨).
- 평가 구간 = 첫 신호~마지막 신호(봉인 전), B&H 동일 구간; 규칙 모델 구간을 학습 모델 폴드에 맞춤(`_eval_window`) → v1107 13개 모두 2012-05-02~2024-12-30.
- 샤프 rf=0·ddof=1·√P, MDD, 승률(분모 r≠0) — 문서·코드 동일.
- purging: 매매 embargo 1+k, 학습 마지막 라벨이 쓰는 가격은 테스트 첫 결정일 전날까지(`calendar.py:225-233`).
- DM Bartlett NW(h−1) = statsmodels HAC; k>1 타겟 MA(k−1) 겹침에 맞는 차수. 부트스트랩 d_t 는 1기간 수익이라 k>1 에도 겹침 없음.
- DSR 수식 Bailey & López de Prado(2014) 와 동일(기간 샤프, V≤0→1/(n−1), N≤1→SR0=0); 10_biva_e20 p 0.98166 재계산 일치.
- Holm step-down 식 올바름. `--sealed` 는 카운터 미증가·N=개발 시도 수, `_sealed` 분리 저장; 봉인 평가 0회(sealed_log.json 없음).
